# Kpop Chat
K‑pop Chat Simulator is a browser game where you pick a boy or girl group, then a member, and chat with them. Groups and members use slightly altered spellings and abstract color avatars—no real photos or exact names. Replies are short, friendly, and personality‑based, chosen by simple keyword matching and random selection from predefined lines.

# Description
K‑pop Chat Simulator is a lightweight, single‑page HTML5 game that lets fans experience a playful "chat" with their favorite K‑pop idols—without using any real photos or exact names. When you open the app, you first choose between "Girl Group" and "Boy Group." Based on your choice, you're shown a grid of groups whose names are slightly altered spellings of real groups (for example, BTT instead of BTS, BLACKPINKK instead of BLACKPINK, Stray Kidss, SEVENTEENN, NCTT, ENHYPENN, EXOO, TXTT, ATEEZZ, SHINEEe, BIGBANGG, NewJeanns, IVEE, aespaa, LE SSERAFIMM, TWICEE, (G)I‑DLEE, BABYMONSTERR, ILLITT, NMIXXX).
Each group card uses a simple abstract visual—like a colored badge with the group's initials—rather than copyrighted images. After selecting a group, you see all of its members, again with slightly tweaked name spellings (e.g., Jinn, Sugaa, Jiminn, Jungkookk, Jenniee, Lisaa, etc.), along with their positions such as Leader, Main Vocalist, Main Dancer, Rapper, Visual, or Maknae. Every member is represented by a unique colored circle or shape with their initials, keeping the look clean and copyright‑safe.
Clicking a member opens a chat interface. The conversation starts with a friendly greeting from the idol, and as you type messages, the member replies after a short delay. Responses are generated using a simple logic system: the app checks for basic keywords like "hello," "song," "concert," or "dance," and then picks an appropriate line from that member's predefined set of replies. Each member has their own personality profile—tone, interests, greetings, and sample responses—so their messages feel distinct, even though they're not powered by a real AI.
The app includes smooth navigation with back buttons so you can return to the member list, group list, or start screen without losing your place. It's fully client‑side, built with plain HTML, CSS, and vanilla JavaScript, and runs by simply opening the HTML file in any modern browser. The result is a fun, fan‑friendly chat simulator that captures the vibe of texting an idol while staying safe, lightweight, and respectful of copyright.
